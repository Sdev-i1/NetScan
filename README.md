# NetScan

Утилита для сканирования локальной сети: обнаружение активных устройств и экспорт результатов в CSV.

## Возможности

- Сканирование заданного диапазона IP-адресов (подсеть или список).
- Определение IP-адреса, MAC-адреса и имени хоста для каждого найденного устройства.
- Экспорт таблицы результатов в CSV.
- Минимальные внешние зависимости.

## Требования

- Python 3.8 или новее.
- Права суперпользователя (root / sudo) на Linux для получения MAC-адресов через ARP.
- Пакеты из requirements.txt (os, socket, csv — из стандартной библиотеки; scapy — опционально).

## Установка:

1. git clone https://github.com/your-username/NetScan.git

2. cd NetScan

3. pip install -r requirements.txt
