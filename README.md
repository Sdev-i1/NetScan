# NetScan

Сканирование локальной сети, обнаружение устройств и экспорт результатов в CSV.

## Возможности

- Обнаружение активных устройств в локальной сети по диапазону IP-адресов
- Сбор базовой информации: IP-адрес, MAC-адрес, имя хоста
- Экспорт результатов в CSV-файл
- Работа без прав суперпользователя (в пределах доступных методов)
- Кроссплатформенность (Windows, Linux, macOS)

## Установка

1. Клонируйте репозиторий:
   
bash
   git clone https://github.com/your-username/NetScan.git
   cd NetScan

1. Установите зависимости:
   
bash
   pip install -r requirements.txt
  
   или
   
bash
   pip install scapy   # если используется scapy
  

Использование

Базовое сканирование

Сканирование стандартного диапазона 192.168.1.0/24:

bash
python netscan.py

Указание произвольной подсети:

bash
python netscan.py --subnet 10.0.0.0/24

Экспорт в CSV

Чтобы сохранить результат в файл, добавьте флаг --csv и укажите имя файла:

bash
python netscan.py --csv devices.csv

Пример содержимого devices.csv:

ip,mac,hostname
192.168.1.1,aa:bb:cc:dd:ee:ff,router.local
192.168.1.42,11:22:33:44:55:66,my-laptop

Дополнительные параметры

--subnet SUBNET    Подсеть для сканирования (по умолчанию 192.168.1.0/24)
--timeout SEC      Таймаут ожидания ответа в секундах (по умолчанию 1)
--csv FILE         Сохранить результат в CSV-файл
--help             Показать справку

Зависимости

· Python 3.8 или новее
· scapy (опционально, для активного ARP-сканирования)
· rich (опционально, для цветного вывода в консоли)

Список библиотек уточняется в requirements.txt.
